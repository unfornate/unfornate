# Локальный парсер банковских выписок

Многостраничное офлайн-приложение для импорта PDF из Т-Банка и Альфа-Банка, нормализации операций, классификации по словарю и построения P&amp;L/кэшфлоу отчётности.

## Быстрый старт

### macOS

```bash
./app/start_server.command
```

Скрипт запускает локальный `python3 -m http.server` на `http://127.0.0.1:8888` и открывает браузер.

### Windows

```bat
app\start_server.bat
```

Будет запущен локальный сервер и открыта стартовая страница.

### Альтернативный запуск

```bash
cd app
python3 -m http.server 8888
```

После этого зайдите на [http://127.0.0.1:8888/index.html](http://127.0.0.1:8888/index.html).

## Структура

```
app/
  index.html            — дашборд
  transactions.html     — импорт и реестр операций
  pnl.html              — отчёт P&L
  cashflow.html         — кэшфлоу, прогноз, регулярные платежи
  budgets.html          — бюджеты и цели
  dictionary.html       — редактор словаря правил
  unknown.html          — быстрые правила по неопознанным операциям
  settings.html         — настройки, импорт/экспорт
  assets/               — pdf.js, Chart.js, SheetJS
  css/base.css          — общий стиль
  data/*.json           — дефолтный словарь и примеры бюджетов/P&L mapping
  js/*.js               — модули приложения
  start_server.command  — запуск на macOS
  start_server.bat      — запуск на Windows
  python/worker.py      — fallback-воркер на pypdf
```

## Основные возможности

- **Импорт PDF** Т-Банк/Альфа (drag-and-drop, мультизагрузка, автоопределение банка, прогресс-бар и таймауты).
- **Парсинг** таблиц выписки прямо в браузере через pdf.js без сервера.
- **Нормализация и классификация** по словарю (`dictionary.json`), поддержка exact/substring/regex и MCC-override.
- **Интерактивный реестр**: фильтры, сортировка, инлайн-правка категорий/комментариев, экспорт CSV/XLSX.
- **Дашборд**: KPI, тренды, распределения, топ расходов.
- **P&L / Cashflow / Budgets**: сводные таблицы, прогнозы, контроль бюджета, регулярные платежи.
- **Редактор словаря**: поиск дубликатов, массовые правки, импорт/экспорт, сброс к дефолту.
- **Неопознанные операции**: создание правил в один клик и моментальная переклассификация.
- **Настройки**: импорт/экспорт журнала, словаря, CSV, выбор валюты и темы.
- **Fallback Python-воркер** (`app/python/worker.py`) для извлечения текста из PDF, если браузерный парсер не справился.

Все данные и словарь хранятся в `localStorage`. Экспорт/импорт осуществляются локально, без передачи данных на серверы.
