# Сайт агентства «Сальто»

Статический многостраничный сайт для маркетингового агентства, который можно развернуть локально.

## Запуск локально

```bash
python3 -m http.server 8000
```

Откройте браузер и перейдите на `http://localhost:8000`.

## Структура

- `index.html` — главная страница.
- Подкаталоги `services`, `cases`, `knowledge`, `webinars`, `club`, `assistants`, `principles`, `about`, `pricing`, `contact`, `faq`, `legal` — отдельные разделы сайта.
- `assets/css/style.css` — стили.
- `assets/js/main.js` — скрипты (бургер-меню, квиз, валидация форм).
- `assets/images/` — папка под медиа (используются заглушки).

Все формы настроены на клиентскую валидацию и могут быть интегрированы с серверной частью или CRM.
